# 更新记录

## 0.1.51

- 任务模型路由恢复细分粒度：构思、设定与人物、章纲/大纲、正文草稿、正文修订、质检修复、风格审稿、章节摘要、连续性检查共 9 种任务，各自可配 provider/model/思考档。
- 恢复旧版默认思考策略：章纲与审稿默认 low，正文草稿默认 off，修订与修复 off/low，其余继承会话。
- 旧项目的 plan/prose 两档配置会自动展开到对应细分任务，不会失效。
- 写作台任务按标题自动归类到细分任务；对话里的 novel_task 可直接指定 9 种 role。

## 0.1.50

- 后台任务增加 20 分钟超时：超时自动中止子代理并标记失败，不再无限跑。
- 手动停止任务也会通知发起它的会话，对话里能看到「已停止」而不是静默结束。

## 0.1.49

- 新增任务简报：正文任务会把章卡、当前正文与结尾、上一章结尾或摘要、连续性要点、字数目标直接打包进任务提示，子代理不需要再反复检索。
- 简报附带执行约定：同一文件最多读两次、按简报直接写、完成即汇报，不要重复校验或顺手开下一个任务。
- 写作台按钮与对话里的 novel_task 都使用简报。

## 0.1.48

- 修复任务路由档位错配：思考档现在按最终生效的 provider/model 解析，避免把基座模型支持的档位传给另一个不支持该档位的模型。
- 子代理失败时附带真实错误：捕获 agent/error，激活结果没有诊断时用它补足失败原因。
- 任务失败信息会写进任务记录，便于定位。

## 0.1.47

- 修复后台任务瞬间“完成”却不执行：改用 subagents.startActivation 真正启动子代理，任务提示随激活一起投递，不再出现创建后空转。
- 主会话不在运行时自动恢复它作为父会话；找不到父会话会明确报错。
- 停止任务会中止对应子代理；停止状态不再被后续失败覆盖。

## 0.1.46

- 后台任务完成/失败/停止后会唤醒发起它的主会话，让助手汇报结果、模型与建议的下一步。
- 汇报请求明确要求不要自行开始新任务或继续改正文，下一步由用户决定。
- 通知文本可测试：包含任务、状态、模型、会话与错误信息。

## 0.1.45

- 任务改为右下角浮动窗口，可拖拽缩放、可收起，不再藏在写作台底部。
- 任务记录落盘到项目内 `.dsh-writing/tasks.json`，重启后仍能看到历史；未完成的任务标记为中断。
- 任务完成/失败/停止会往发起它的主会话注入一条通知，对话里能看到结果。
- 项目菜单新增「任务记录」入口，徽标改为开关任务窗口。

## 0.1.44

- 修复对话发起的任务不可见：任务面板与任务记录改为读取宿主任务队列，不再只显示写作台自己派发的任务。
- 任务列表按执行中/排队中优先排序，显示实际模型、状态与排队位置，可直接停止或打开子会话。
- 对话输入区新增任务徽标：有排队或执行中任务时显示「任务 N」，点一下打开写作台。
- 新增 /deepnovel/api/tasks/all：跨项目返回任务队列概览，写作台与徽标共用同一份数据。

## 0.1.42

- 修复阅读排版不生效：字号、字体、版心宽度现在真正应用到正文预览。
- 标题字号跟随正文字号缩放，阅读设置变化时预览立即更新。
- 编辑器同步使用所选字体字号，编辑态也能看出排版差异。

## 0.1.41

- 对话内正文策略：默认对话只做编排，整章生成/扩写交给 novel_task 的正文模型；直接改正文会被拒绝并提示改走队列。
- 项目设置新增「对话内直接改正文」开关，打开后对话模型可以直接写正文。
- novel_route 支持读写该开关；队列子代理不受限制。
- 提示词说明默认编排与开关行为。

## 0.1.40

- 新增 novel_style_check：检查「不是…是…」对照句、短句开段比例、总结/感悟式表达和自定义禁用句式，返回行号与样例。
- 提示词要求写正文提案前先跑文风检查，对照句与总结句必须为 0，短句开段不超过 25%。
- 文风检查只报告不改写，命中项由模型改写后再提案。

## 0.1.39

- 写作 Agent 增加写文件守卫：用 write/edit/apply_patch 或命令行直接改 manuscript、plot、world、characters、continuity、revisions、references、deepnovel.json 会被拒绝。
- 守卫会提示改用 novel_write 的 propose/append/patch，避免绕过提案审批和修订记录。
- 只读命令（Get-Content、cat、grep 等）和项目外文件不受影响。

## 0.1.38

- novel_write 增加 action=append：只提交新增段落，避免扩写时整章重发。
- novel_write 增加 action=patch：用 find/replace 改局部，find 必须唯一命中。
- append/patch 同样生成提案并返回字数统计，净字数没有增加会给出警告。
- 提示词明确：扩写用 append、局部修改用 patch，只有整章重写才用 propose。

## 0.1.37

- 提案列表自动清理死提案：内容与当前文件相同、或基准已失效的提案会被移除，不再堆积在收件箱。
- novel_write 新增 action=list，可以列出待处理提案及其 id，AI 能直接应用已有提案而不是重复提交。
- 相同内容报错时给出当前净字数、章卡目标和还差多少字，方便模型按缺口补写。

## 0.1.36

- 提示词新增「补字数 / 扩写正文」步骤：先统计差额、再按场景补写、分次应用并复核，净字数必须每版增加。
- novel_count 的章节统计增加 remaining（距下限还差多少字）与是否超上限。
- 正文写提案返回字数统计：当前净字数、提案净字数、增减量、章卡目标、差额和进度；净字数没增加时附带警告。

## 0.1.35

- 提案内容与当前文档完全相同时不再生成提案，工具直接返回错误并说明没有写入任何字。
- 同一会话对同一文档连续提交相同内容会报错，提示已重复几次，迫使模型真正改写而不是空转。
- 相同内容的待处理提案（含磁盘上已有的）会被复用，不再堆积重复提案。
- 提示词补充：扩写必须产生实际差异，字数用 novel_count 核对。

## 0.1.34

- 新增 novel_count 工具：按章/卷/全书统计净字数，scope=text 可统计任意文本。
- 统计同时给出字符总数、去空白字符数、行数、段落数、直/弯/角引号数，便于和外部脚本核对。
- 从章卡自动解析篇幅目标（如 3,500–4,200 字）并给出进度与是否达标。
- 字数口径收敛到一处实现，资料库与统计工具共用同一规则。

## 0.1.33

- 修复「内容没变也报成功」：propose 时若新正文与当前文档完全一致，返回 unchanged:true 并提示不要 apply。
- apply 遇到相同内容不再写盘，返回 applied:false、reason=no-change 并说明没有写入任何字。
- novel_write 工具在 no-change 时返回 ok:false，避免 AI 以为已经改完而反复提交同一份正文。

## 0.1.32

- 并行判定改为文件作用域：两个任务只要不写同一文件、也不形成读写冲突，就可以并行。
- 任务可声明多文件的读/写集合，目录前缀同样参与冲突判断。
- 写正文任务按章节定位到 `manuscript/<章>.md`，不同章节可以同时写，同一章自动排队。
- 未知任务按「整个项目写」处理，宁可排队也不制造并发写冲突。
- 新增 novel_task 工具：对话里可以查看队列、提交带作用域的任务、取消任务；直接写仍受项目写锁保护。

## 0.1.31

- 任务执行加入队列：只读检查类任务可并行（默认最多 2 个），写正文、规划、设定类任务串行排队。
- 同一任务重复提交会复用已有任务，不再重复起子代理。
- 排队中的任务显示排队位置，可以取消；运行中的任务可以停止，并解除对应子代理会话。
- 任务面板与任务记录区分「排队中 / 执行中 / 已完成 / 失败 / 已停止」。

## 0.1.30

- AI 任务改为后台子代理执行：宿主创建带模型的子会话并投递任务，写作台不再被强行切到对话。
- 子代理继承项目目录、写作预设和父会话关系，自动带上项目上下文。
- 写作台底部新增常驻任务面板：显示执行中/已完成/失败、实际模型和思考档，可打开子会话、停止、重试。
- 任务面板与任务记录保存在本地，切换文档或会话后仍在。
- 任务路由在执行时生效：按「规划/检查」「写正文」使用项目设置里的模型与思考档，留空跟随当前会话。
- 宿主不支持后台子代理时，自动回退到原来的写作会话发送方式。

## 0.1.29

- 文档树在当前章节下展开「章卡 / 正文 / 摘要」，正文有了独立入口。
- 章节页点击章节默认打开正文（没有正文才打开章卡），并补章卡/正文/摘要三个显式入口。
- 增加任务模型路由配置：项目内按「规划/检查」与「写正文」记录模型和思考档，留空跟随当前会话。
- 项目设置页新增「任务模型」区块；AI 可用 novel_route 读取或修改路由。
- 思考档不被模型支持时自动回落并在提示里说明，不阻断任务。

## 0.1.28

- 新增资料库：项目内 references 索引和原文副本，支持目录导入、类型筛选、搜索、预览和删除；DOCX/PDF 文本可直接提取；AI 通过 novel_reference 读取。
- 文档页增加修订历史：查看历史版本、预览并恢复；手动保存和恢复都会先产生备份。
- 增加待处理提案收件箱：AI 生成的创作/修改提案在顶栏显示数量，逐行 diff 可应用或拒绝。
- 字数统计改为可读正文字数，不再把 Markdown 标记和代码块计入。
- 文风页改为分组契约视图，视角/时态等枚举显示中文；修复搜索空结果导致的 spread 崩溃。
- 增加本地草稿恢复、侧栏/信息栏开关、窄窗口浮层布局和清爽/暖色主题切换。
- 增加任务记录：保存任务状态、失败重试、停止运行中任务和打开对应会话。
- 增加专注写作模式：隐藏导航和上下文栏，Esc 退出；阅读排版可设置字号、字体和版心宽度。
- 导出改为整本 / 按卷 / 单章范围，并支持 DOCX 资料导入。

## 0.1.27

- 彻底替换写作链路：文档为唯一事实来源，Markdown 保存创作内容，索引只保留对象关系。
- 主创 Agent 改用项目地图、按需读取、检索、写提案、连续性账本。
- 删除构思/卷计划/章纲的批量 JSON 字段生成、自动审核与自动修复。
- 写作台改为页面导航 + 编辑区 + diff 审批；项目选择调用系统目录对话框，并补最近项目、任务状态和项目设置。
- 写作台恢复项目 / 构思 / 文风 / 设定 / 大纲 / 章节页面；AI 按钮打开正常 DSH 写作会话并显式设置项目根，不再创建隐藏助手。
- 开书改为 AI 访谈/给方向，不再使用必填准备表单。
- 创建改为原子提案：元数据 + 正文一起确认，拒绝不留下空对象；工具 novel_create 不再直接建空对象。
- 写作台移除手动新建设定/人物/卷/章卡入口，创建全部走 AI 任务。
- AI 任务改为找到项目 Workspace、创建正常 DSH 会话、自动发送任务，再打开对话；失败时回退为预填任务。
- 写作台补搜索、Markdown 导出和全局 AI 指令；删除手动创建 API。
- 任务派发拆为可测纯函数：Workspace 查找、正常会话创建、自动发送。
- 增加项目 workflow 阶段与按钮门禁：方向未定案不能建设定/人物/卷/章卡，地基未完成不能建卷，章卡未就绪不能写正文。
- 每页顶部增加阶段进度条：方向 → 地基 → 结构 → 写作 → 连续性；页面改为内容优先，移除重复说明文字。
- 项目页与构思页解除重复：book.md 只在构思页查看和编辑；页面按钮按阶段解锁。
- 写作台加入项目文档树、编辑/分栏/预览三种编辑器模式、字数统计和 Ctrl/⌘+S 保存快捷键；文档默认阅读视图。
- 阅读区提供文档信息与本文目录；搜索、导出、设置等收进项目操作菜单。
- 整体壳层重做：引入统一设计系统，顶栏、单一侧栏、内容舞台和右侧上下文栏全部重排；文档按正常 Markdown 渲染，不再做纸张式装饰。
- 手动编辑改为自动保存，增加保存状态和 hash 冲突检测；移除文档页「返回列表」。
- 左右栏宽度改为随窗口自适应，内容版心随可用宽度扩展。
- 加深导航层级：15px 导航字号、图标容器、计数胶囊、主题色侧栏和阶段卡；主题变量可替换，便于后续接入旧版主题。
- 文档树默认按当前文档展开、分卷折叠并支持筛选，避免章节增长后左栏失控。
- 连续性账本改为结构化视图，不再直接展示 JSON。
- 无提案时收起右侧提案栏，减少空白占位。
- 保留项目元数据、写作要求和文风；旧数据迁移到 `.deepnovel-backup/`。
