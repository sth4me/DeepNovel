# 更新记录

## 0.1.34

- 新增 novel_count 工具：按章/卷/全书统计净字数，scope=text 可统计任意文本。
- 统计同时给出字符总数、去空白字符数、行数、段落数、直/弯/角引号数，便于和外部脚本核对。
- 从章卡自动解析篇幅目标（如 3,500–4,200 字）并给出进度与是否达标。
- 字数口径收敛到一处实现，资料库与统计工具共用同一规则。

## 0.1.33

- 修复「内容没变也报成功」：propose 时若新正文与当前文档完全一致，返回 unchanged:true 并提示不要 apply。
- apply 遇到相同内容不再写盘，返回 applied:false、reason=no-change 并说明没有写入任何字。
- novel_write 工具在 no-change 时返回 ok:false，避免 AI 以为已经改完而反复提交同一份正文。

## 0.1.32

- 并行判定改为文件作用域：两个任务只要不写同一文件、也不形成读写冲突，就可以并行。
- 任务可声明多文件的读/写集合，目录前缀同样参与冲突判断。
- 写正文任务按章节定位到 `manuscript/<章>.md`，不同章节可以同时写，同一章自动排队。
- 未知任务按「整个项目写」处理，宁可排队也不制造并发写冲突。
- 新增 novel_task 工具：对话里可以查看队列、提交带作用域的任务、取消任务；直接写仍受项目写锁保护。

## 0.1.31

- 任务执行加入队列：只读检查类任务可并行（默认最多 2 个），写正文、规划、设定类任务串行排队。
- 同一任务重复提交会复用已有任务，不再重复起子代理。
- 排队中的任务显示排队位置，可以取消；运行中的任务可以停止，并解除对应子代理会话。
- 任务面板与任务记录区分「排队中 / 执行中 / 已完成 / 失败 / 已停止」。

## 0.1.30

- AI 任务改为后台子代理执行：宿主创建带模型的子会话并投递任务，写作台不再被强行切到对话。
- 子代理继承项目目录、写作预设和父会话关系，自动带上项目上下文。
- 写作台底部新增常驻任务面板：显示执行中/已完成/失败、实际模型和思考档，可打开子会话、停止、重试。
- 任务面板与任务记录保存在本地，切换文档或会话后仍在。
- 任务路由在执行时生效：按「规划/检查」「写正文」使用项目设置里的模型与思考档，留空跟随当前会话。
- 宿主不支持后台子代理时，自动回退到原来的写作会话发送方式。

## 0.1.29

- 文档树在当前章节下展开「章卡 / 正文 / 摘要」，正文有了独立入口。
- 章节页点击章节默认打开正文（没有正文才打开章卡），并补章卡/正文/摘要三个显式入口。
- 增加任务模型路由配置：项目内按「规划/检查」与「写正文」记录模型和思考档，留空跟随当前会话。
- 项目设置页新增「任务模型」区块；AI 可用 novel_route 读取或修改路由。
- 思考档不被模型支持时自动回落并在提示里说明，不阻断任务。

## 0.1.28

- 新增资料库：项目内 references 索引和原文副本，支持目录导入、类型筛选、搜索、预览和删除；DOCX/PDF 文本可直接提取；AI 通过 novel_reference 读取。
- 文档页增加修订历史：查看历史版本、预览并恢复；手动保存和恢复都会先产生备份。
- 增加待处理提案收件箱：AI 生成的创作/修改提案在顶栏显示数量，逐行 diff 可应用或拒绝。
- 字数统计改为可读正文字数，不再把 Markdown 标记和代码块计入。
- 文风页改为分组契约视图，视角/时态等枚举显示中文；修复搜索空结果导致的 spread 崩溃。
- 增加本地草稿恢复、侧栏/信息栏开关、窄窗口浮层布局和清爽/暖色主题切换。
- 增加任务记录：保存任务状态、失败重试、停止运行中任务和打开对应会话。
- 增加专注写作模式：隐藏导航和上下文栏，Esc 退出；阅读排版可设置字号、字体和版心宽度。
- 导出改为整本 / 按卷 / 单章范围，并支持 DOCX 资料导入。

## 0.1.27

- 彻底替换写作链路：文档为唯一事实来源，Markdown 保存创作内容，索引只保留对象关系。
- 主创 Agent 改用项目地图、按需读取、检索、写提案、连续性账本。
- 删除构思/卷计划/章纲的批量 JSON 字段生成、自动审核与自动修复。
- 写作台改为页面导航 + 编辑区 + diff 审批；项目选择调用系统目录对话框，并补最近项目、任务状态和项目设置。
- 写作台恢复项目 / 构思 / 文风 / 设定 / 大纲 / 章节页面；AI 按钮打开正常 DSH 写作会话并显式设置项目根，不再创建隐藏助手。
- 开书改为 AI 访谈/给方向，不再使用必填准备表单。
- 创建改为原子提案：元数据 + 正文一起确认，拒绝不留下空对象；工具 novel_create 不再直接建空对象。
- 写作台移除手动新建设定/人物/卷/章卡入口，创建全部走 AI 任务。
- AI 任务改为找到项目 Workspace、创建正常 DSH 会话、自动发送任务，再打开对话；失败时回退为预填任务。
- 写作台补搜索、Markdown 导出和全局 AI 指令；删除手动创建 API。
- 任务派发拆为可测纯函数：Workspace 查找、正常会话创建、自动发送。
- 增加项目 workflow 阶段与按钮门禁：方向未定案不能建设定/人物/卷/章卡，地基未完成不能建卷，章卡未就绪不能写正文。
- 每页顶部增加阶段进度条：方向 → 地基 → 结构 → 写作 → 连续性；页面改为内容优先，移除重复说明文字。
- 项目页与构思页解除重复：book.md 只在构思页查看和编辑；页面按钮按阶段解锁。
- 写作台加入项目文档树、编辑/分栏/预览三种编辑器模式、字数统计和 Ctrl/⌘+S 保存快捷键；文档默认阅读视图。
- 阅读区提供文档信息与本文目录；搜索、导出、设置等收进项目操作菜单。
- 整体壳层重做：引入统一设计系统，顶栏、单一侧栏、内容舞台和右侧上下文栏全部重排；文档按正常 Markdown 渲染，不再做纸张式装饰。
- 手动编辑改为自动保存，增加保存状态和 hash 冲突检测；移除文档页「返回列表」。
- 左右栏宽度改为随窗口自适应，内容版心随可用宽度扩展。
- 加深导航层级：15px 导航字号、图标容器、计数胶囊、主题色侧栏和阶段卡；主题变量可替换，便于后续接入旧版主题。
- 文档树默认按当前文档展开、分卷折叠并支持筛选，避免章节增长后左栏失控。
- 连续性账本改为结构化视图，不再直接展示 JSON。
- 无提案时收起右侧提案栏，减少空白占位。
- 保留项目元数据、写作要求和文风；旧数据迁移到 `.deepnovel-backup/`。
