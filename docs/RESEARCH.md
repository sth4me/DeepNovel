# 开源写作工具调研（2026-10）

目标：找可借鉴的“长篇写作”功能与交互，不复制代码。

## novelWriter

- 纯文本 + 轻量格式，项目树组织章节/笔记，支持拖拽排序。
- 三种视图：项目树、Novel View（按标题看结构）、Outline View（表格列出章节/场景与元数据）。
- 可选右侧文档查看器：写作时并排看设定/笔记，不离开正文。
- Focus Mode：隐藏除编辑器外的全部界面（快捷键 F8）。
- Build Manuscript：把章节合成为 ODT/DOCX/PDF/HTML/Markdown。
- 写作统计、全局搜索、可配置列、主题。
- 参考：
  - [Features](https://novelwriter.io/features.html)
  - [The Main Window](https://novelwriter.io/docs/user_interface/main_window.html)
  - [Introduction](https://novelwriter.io/docs/usage/introduction.html)

## Manuskript

- 从一句话 premise 扩到段落/摘要，角色、情节、世界观、物品管理。
- Outline 模式 + 索引卡（index cards），章节/场景重排。
- 故事线（Story line）视图，俯视多线推进。
- 专注/免打扰写作，模板与写作模式。
- 导出 HTML/ePub/ODT/DOCX/PDF；自动保存、拼写检查、词频分析。
- 参考：
  - [Snap Store: Manuskript](https://snapcraft.io/manuskript)

## 共同模式

1. **左侧结构树 + 中间编辑器 + 右侧参考/检查器**，而不是把所有东西塞进一个表单。
2. **结构视图与写作视图分离**：大纲/卡片用于规划，正文用于沉浸写作。
3. **专注模式**是高频需求：写作时隐藏导航与检查器。
4. **导出/编译**是完成闭环：章节写完要能变成一本书。
5. **项目级元数据**（角色、地点、物品、伏笔、时间线）比“章节正文”更能支撑长篇一致性。
6. **写作统计与目标**提供正反馈。
7. 快捷键、搜索、可配置列/面板，是长期使用后的效率关键。

## 本轮已吸收

- 主面板三栏 + 专注模式（隐藏左右栏）。
- 项目级设定（角色/地点/规则/势力/物品）与章节注入。
- 故事状态：时间线、伏笔列表、未回收伏笔。
- 导出全书 Markdown。
- 写作统计：总字数、目标字数、定稿章数。
- 质检/修复分离，自动化参数放到项目配置（自动检测、自动修复、轮数、通过线、批量数、目标字数）。
- 章节阅读区点选段落重写；多余按钮收进统一“质检”卡。
