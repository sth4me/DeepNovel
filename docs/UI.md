# 写作台

写作台是项目工作台，不是第二个 AI。文档是唯一事实来源；AI 只通过正常的 DSH 会话工作。

## 形态

```text
左：项目 / 构思 / 文风 / 设定 / 大纲 / 章节
中：页面或文档编辑
右：修改提案与 diff
```

顶部：项目名、路径、阶段、任务状态、搜索、导出、项目设置、换项目、刷新。

## 布局

应用使用统一设计系统：顶栏 + 单一侧栏（工作台导航和文档树）+ 内容舞台 + 文档上下文/提案栏。

```text
顶栏
────────────────────────────────────────
侧栏 | 内容舞台 | 上下文/提案
```

- 单一侧栏合并工作台导航和项目文档树，避免两条窄栏；导航使用图标、字号和计数胶囊强化层级；
- 文档树负责定位具体文档；默认只展开当前文档所属分组，分卷按卷折叠，顶部可筛选；
- 中间默认显示阶段页面，打开文档后显示编辑器；
- 打开文档默认进入阅读预览；编辑器支持编辑、分栏、预览三种模式；手动修改会自动保存，Ctrl/⌘ + S 立即保存。
- 打开文档时右栏显示文档信息和本文目录；有修改提案时切换为提案；两者都没有时收起右栏。
- 阅读视图使用纸张式正文面板，正文版心收窄，标题层级和列表按 Markdown 渲染。

## 页面归属

每个对象只在一个页面维护，其他页面只做导航：

| 页面 | 负责内容 |
| --- | --- |
| 项目 | 阶段、统计、下一步、项目设置 |
| 构思 | `plot/book.md` 的查看、编辑、讨论、整理 |
| 文风 | `manifest.style` 和文风检查 |
| 设定 | 世界观、人物 |
| 大纲 | 卷、剧情点、章卡规划 |
| 章节 | 章卡、正文、摘要与连续性 |

项目页不再展示或编辑 `book.md`；有方向时只显示“故事方向已定”和“去构思页查看”。

## 流程门禁

每个页面顶部固定显示阶段条：方向 → 地基 → 结构 → 写作 → 连续性；下面是目标、检查项和唯一推荐动作。说明文字不再承担流程解释。写作台按项目实际文档推导阶段，不按按钮自由跳：

```text
开书方向 → 地基（设定/人物） → 结构（卷/章卡） → 写作（正文） → 连续性
```

- 方向未写入 `plot/book.md`：只能开始开书/讨论方向；设定、人物、卷、章卡、正文按钮禁用。
- 没有设定和主要人物：卷和章卡按钮禁用。
- 没有卷：章卡按钮禁用。
- 没有章卡：正文按钮禁用。
- 没有正文：连续性按钮禁用。

按钮被禁用时会显示当前阶段和缺少的前置条件。

> 运行中的宿主需要重启/重载后才会返回新的 `workflow` 字段。

## 全局 AI 指令

顶栏输入框可以直接说下一步要做什么，例如：

- 开始开书，写一个偏江湖日常的武侠；
- 补三条门派规矩；
- 把人物减少到四个；
- 规划下一卷，换一种冲突方式。

发送后和快捷任务一样，进入正常 DSH 写作会话。

## AI 任务

写作台里的 AI 按钮不创建隐藏助手，也不直接调模型。

1. 点击 AI 动作；
2. 写作台找到项目对应的正常 DSH Workspace；
3. 创建/复用 `novel-writer` 会话；
4. 自动发送任务；
5. AI 在会话里提问、给方案、写提案；
6. 用户确认后应用。

没有 UI 时，直接在 DSH 对话里使用同一套 `novel_*` 工具。

所有 AI 任务开始前都会显式调用 `novel_project action=open`，项目目录不依赖 DSH 当前工作目录。

## 开书

- 没有必填的题材/写作要求表单；
- 点「开始开书」直接创建 AI 任务；
- AI 信息不足时先问问题或给方向；
- 方向确认后才给最小开书方案；
- 方案确认后才创建对象。

## 页面

- **项目**：统计、下一步、AI 任务、项目设置；
- **构思**：`plot/book.md` 故事脊柱，AI 讨论/整理；
- **文风**：当前文风字段摘要，AI 提炼/检查；
- **设定**：按 AI 分类展示，AI 补设定/整理分类/查冲突；
- **大纲**：卷、剧情点、章卡，AI 规划/检查重复；
- **章节**：章卡/正文/摘要状态、上一/下一章、AI 写章/修订/检查连续性。

页面不提供手动新建空对象入口；新建全部来自 AI 原子的创建提案。已有文档可以直接编辑。

连续性账本不直接展示 JSON，而是按事实、知情、伏笔、时间线和章节交接分组展示；需要排错时可切原始 JSON。

## 编辑与保存

- 打开已有文档默认进入阅读预览；
- 切到「编辑」或「分栏」直接修改；
- 停止输入约 0.8 秒自动保存到项目文件；
- `Ctrl/⌘ + S` 立即保存；
- 保存状态显示「保存中 / 已保存 / 保存失败」；
- 如果文档被 AI 或其他操作改过，保存会检测 hash 冲突并提示重新读取，不覆盖新内容。

AI 写入仍走提案确认流程，和手动编辑不是同一条链路。

## 搜索与导出

- 顶栏「搜索」跨文档查找原文，点结果打开对应对象；
- 顶栏「导出」生成 Markdown 全文并下载。

## 项目选择

- 「选择项目目录」调用宿主系统目录选择器；
- 「新建项目」先选目录，再填写书名；
- 最近打开列表；
- 目录选择器不可用时，欢迎页仍可手动输入路径。

## 开关

写作台是独立组件行 `deepnovel-ui`。在插件管理里关闭该行即可隐藏写作台，不影响宿主 API 和 Agent 工具。
