# 写作台 UI

## 形态

写作台是 DSH 的**全局主面板**，不是会话侧栏，也不要求先创建会话。

- 侧栏入口：`sidebar.panellist` 注册「写作台」图标。
- 面板：`main` key 注册 `novel-writer-desk`。
- 三栏布局：左侧流程 rail / 中间工作区 / 右侧流程与 AI 检查器。
- 项目由项目目录决定，不绑定 Session；目录记忆在 `localStorage`。

## 主题

顶栏「主题」可切换，存 `localStorage`（`dsh.novelWriter.theme`），只作用于写作台子树，不影响 DSH 其他界面：

| 主题 | 气质 |
|---|---|
| 跟随 DSH | 沿用宿主配色 |
| 纸墨 | 米黄纸面 + 赭石强调 |
| 墨夜 | 深色墨底 + 暗金强调 |
| 木纹 | 深棕木纹背景 + 暖金强调，木质书架的陈旧质感 |
| 护眼灰 | 低饱和灰白 |

主题通过覆盖写作台根节点的 `--dsw-alias-*` 变量实现，所有组件自动跟随；木纹主题额外叠加多层渐变模拟木纹。

## 布局

1. **顶栏**：项目名、目录、下一步、字数进度条（目标百分比）、主题、面板开关、专注模式、刷新、切换项目。
   - **刷新**（`↻`）：重新拉取项目状态并重渲染（不动会话、不重跑 AI）。写作台平时会自动同步：Host 监听各章正文文件（Electron 用 `fs.watch`、其它环境轮询），写作助手或外部编辑器改动 `draft.md` / `final.md` 后页面自动刷新；手动刷新用于兜底（监听不可用、后台标签页被降频、或想立刻确认）。同步中显示 `…`，完成后短暂显示 `✓`。
2. **左栏**：项目 → 构思 → 文风 → 设定 → 大纲 → 章节，带状态与说明。
3. **中间工作区**：
   - 项目：写作统计（近 14 天字数 / 定稿完成度）、结构统计（伏笔回收率 / 各卷字数 / 出场 Top）、数据健康（章纲未确认、缺字段、草稿未定稿、坏关系、超字数、摘要缺失、伏笔停滞、孤立文件，可一键补摘要 / 确认章纲 / 批量定稿 / 清理坏关系 / 刷新过期定稿 / 清理孤立文件）、**写作要求（共享，可按设定/大纲/草稿/修订阶段生效）**、**技能库**（内置技法作为内置技能 `craft-*`、项目导入（`<projectRoot>/.dsh/skills`、`.agents/skills`）与全局导入（`DSH_HOME/novel-writer/library/skills/`，所有写作项目可用）三类；导入弹窗可选「项目 / 全局」并显示写入路径，列表 scope 徽标（内置 / 项目 / 全局 + 覆盖内置）、内置开关、删除 / 预览按 scope；优先级 项目 > 全局 > 内置；AI 按需读取并自行判断是否适合本章）、**数据层**（显示 SQLite 数据库大小 / WAL 大小 / FTS 索引条数 / schema 版本，按钮「重建检索索引」（reindex）、「导出纯文件项目」（export-file-project，完成后显示导出路径）、「导入纯文件项目」（选择纯文件项目目录，覆盖当前项目、先自动备份，完成后显示备份路径）、「刷新」（data-status）；`dataLayer` 为 null 时整卡不渲染）、System 模板（按任务覆盖；显示内置版本 `v{n}`，内置默认改版后标「默认已更新」并可一键改用新版）、模型分配、提示词注入、自动化设置、导出、**搜索**（全局检索章节正文 / 章纲 / 设定 / 摘要，结果带类型与章号徽标、`[[...]]` 命中片段高亮，显示结果条数与耗时，点结果跳到对应页面）、最近运行（可按类型筛选、查看 system/输入/输出、显示章节号与时间、清理旧记录）。
   - 构思：候选卡片 + 已确认构思编辑器；**灵感模式**（生成桥段点子，可一键用作构思方向，历史保存在 `.dsh-writing/inspirations.json`）；**拆书**（三阶段流水线：结构编年 / 人物与设定 / 技法与钩子，结果按分区展示并标出失败阶段，历史保存在 `.dsh-writing/deconstructions.json`）。
   - 文风：契约字段分组编辑（基础 / 语言质感 / 对白与节奏 / 三档规则 / 禁忌 / 题材适配 / 标题与补充）+ 模板列表（9 个内置模板，按分组排序、题材标签、示例段）；三档规则为**必须贯彻 / 绝对禁止 / 按场景调节**，示例段落 2–3 段（生成时作为语感锚点，模板会携带）；模板可保存为自定义、导入 JSON、导出 JSON。
   - 设定：角色/地点/规则/势力/物品分类 + 条目卡；角色卡可「存入库」并在「角色库」区块跨项目导入/合并或删除；「能力」页管理境界层级、角色当前战力和按章能力变化；角色卡可导出（剪贴板）/导入（含覆盖与关系合并）；**关系**页为 SVG 人物关系网（节点可拖拽并保存布局、重置布局、导出 SVG/PNG、点节点看角色卡与出场章节）；**伏笔**页为时间线看板（埋设/回收、未回收高亮、点章号跳大纲）。
   - 大纲：卡片 / 表格 / 图谱 / 编辑四视图；多卷切换、卷内生成、章节移动、确认本卷、**批量重生成**（选择起止章，二次确认后覆盖范围内章纲并重置为待确认；顶部指令作为本次重生成要求）；**图谱**视图展示章节节点、相邻衔接线与伏笔虚线，可导出 SVG/PNG。
   - 章节：按卷筛选、章节目录 + 阅读/编辑区；**写本卷剩余**（先校验章纲已确认，每轮最多 10 章）、**定稿本卷草稿**。
4. **右栏**：流程状态 / AI。
5. **底部下一步条**：显示阻塞项并直达下一步。

## 章节页

- 顶部固定一条**章节操作条**：上一章/下一章、编辑、修复、定稿；「更多」中放上下文、检测、单轮修复、选段开关、回到顶部；滚动阅读时仍然可用。
- 标题 + 质检/AI/手动编辑徽标。
- 写作动作全部集中在顶部固定操作条，正文区不再重复放按钮：主操作是上一/下一、编辑、按意见修订、检测、修复、定稿；「更多」放上下文、重新生成、单轮修复、下一章、连续写、撤销重写、选段、回到顶部。
- 本章修订要求 + 正文模型/思考等级提示。
- 质检卡只展示状态与详情，不再重复「检测/修复」按钮。
- 修订历史：版本 diff / 恢复。
- 段落选择：点第一段再点第二段；底部固定浮动条「预览重写 / 取消」。默认关闭鼠标选段，避免误触；可在操作条或选择栏开启，精确段号始终可用。
- 局部重写先出**差异预览**：可逐块勾选接受/拒绝，确认后才写盘；应用后可在本章提示条「撤销本次重写」。
- 质检问题如果带段落定位，点击问题会滚到对应段落并高亮。
- 切换章节会记住该章滚动位置。
- 快捷键：`Alt+←/→` 上一/下一章，`E` 编辑，`A` 检测，`Esc` 清除选段（输入框内不触发）。
- 手动编辑：整章 textarea，顶部保存/取消，Ctrl/Cmd+S 保存。
- 连续性与摘要卡：生成本章摘要、本地连续性检查、AI 连续性检查；定稿时自动生成摘要。
- 操作条「更多」中另有**润色 / 扩写 / 缩写**（复用修订流程，只改文字或增删细节，走修订历史可回滚），以及「复制正文」。
- 章节页有**伏笔提醒**卡：本章应回收的伏笔与仍未回收的清单，点章号跳大纲。
- 修订要求输入框旁支持「插入项目要求」与「复制修订要求」。
- 章节列表项显示规则质检状态（规则未过）与风格分。
- 操作条有「去 AI 味」按钮（ghost，在修复与定稿之间）：弹窗标题「第 N 章 · 去 AI 味」，提示「只改表达不改剧情，先预览改写结果；确认后再写入正文。」；预览显示「改写 N 处」与「AI 味：前 → 后」、可编辑改写文本；按钮「预览」→「应用改写」。被助手占用时禁用并提示。
- 质检卡显示 AI 味徽标「AI 味 轻/中/重 · 分数」；详情列出「AI 味：level · score/100」与前 5 条命中标记（类型 + 原文片段）。

## 并行任务

- 顶栏「任务 N」和右下角任务托盘显示当前所有运行中任务。
- 每项显示：动作（如“第 3 章 · 生成草稿”）、真实阶段（组装上下文 / 生成正文 / 规则质检 / 风格审稿 / 修复）、已耗时。
- 同资源动作不报错，而是自动排队；任务托盘显示「排队 N」，可移除排队项。
- 不同章节/不同阶段可并行；托盘可收起，可单项重试/取消，也可全部取消；连续写章支持「暂停（当前章后）」。
- 当前页任务仍在顶栏显示秒数与取消按钮。
- 写作助手发起的占用也显示在托盘：「写作助手 · 第 N 章」/「写作助手 · 批量章节」等；这类占用没有取消按钮（可在 AI 页停止对话），与界面任务按同一套规则排队/互斥。
- 被占用资源的按钮会禁用并提示「写作助手正在处理该资源」；`run()` 兜底再提示一次，避免点了没反应。
- 右侧流程面板保留「最近任务」：完成/失败时间与重试入口。

## AI 页

- 右栏「AI」页内嵌 DSH 官方对话界面（`conversation.content` embedded），标题「写作助手」，输入框提示「给写作助手发消息」；每个项目一个隐藏会话。
- 工具栏（「写作助手」标题右侧）有「压缩上下文」按钮（在「新对话」左侧，ghost）：确认弹窗提示「把较早的对话历史摘要成一段，保留最近原文；不会影响项目数据。会话正在生成时无法压缩。」；成功后 toast「已压缩 N 条历史（约 M tokens）」，消息太少时提示「对话还太短…」。
- 助手通过 `novel_*` 工具读写项目；改正文支持小步 `patch`（只替换片段、不调用模型、留修订备份），工具报错返回 `{ ok:false, tool, error, hint }`，不会因单次错误中断对话。
- 助手写操作会占用对应资源锁（显示在任务托盘），在 AI 页停止对话即可释放；工具输出按页/块返回，长章节用 `range` / `maxChars` 续读。
- 数据层规则、patch 参数、上下文预算与中断恢复见 [AI-ASSISTANT.md](AI-ASSISTANT.md)。

## 项目选择

- 首次进入或切换项目时显示项目选择页：选择目录、手输绝对路径、最近项目。
- 最近项目可逐个删除或清空；删除只清 localStorage，不删目录。
- 手输路径示例使用通用占位，不写死开发目录。

## 项目安全

- 项目页「项目快照」：创建/恢复 `story`（含 `project.db`）与 `.dsh-writing` 的快照，复制前先 checkpoint WAL；恢复前自动生成 pre-restore 备份，恢复后自动重开数据库。
- 「角色索引」：汇总角色出场章节与最后出场，标出未入设定的角色。
- 「补全缺失摘要」：批量补全已有正文的章节摘要。
- 导出：Markdown / HTML / EPUB / DOCX（DOCX 含标题、目录域、章标题样式）。

## 解除初始化

项目页“危险操作：解除初始化”：

- 自动解除：两次确认，把 `story/` 与 `.dsh-writing/` 移到项目内 `.deepnovel-backup/<时间>/`，不直接删除。
- 手动方案：显示备份提醒与手动删除步骤，可复制。

## 响应式

- >1180px：完整三栏。
- ≤1180px：右侧检查器默认收起，可点「面板」以抽屉打开。
- ≤1000px：隐藏顶栏长下一步文案。
- ≤900px：显示移动步骤下拉；≤860px 隐藏 rail，工作区单列。

## 专注模式

顶栏「专注」隐藏左右栏，Esc 退出，正文区域成为唯一焦点。

## 数据通道

- 客户端通过 Host 注册的 loopback HTTP 路由访问数据：
  - `/novel-writer/project-state`（含 `activeLocks`）、`/project-runs`（返回 `{ runs, locks }`）、`/project-action`、`/project-cancel`
  - `/project-chapter`、`/project-revision`、`/context`
  - `/models`、`/model-info`
- 仅 loopback；生成动作按资源加锁，可取消。写作助手与界面共用同一套锁（`chapter:<章号>`、`chapter:batch`、`outline`、`bible`、`style`、`premise`、`project*`），`project` / `project:import` / `project:export` 与任何锁互斥。
- 并发粒度：章节动作按章号互斥（第 3 章生成时可同时生成第 4 章），大纲、设定、构思、文风各一把锁互不阻塞；导出、搜索、改标题、保存提示词等不锁。前端只锁当前页，切页即可并行操作。
- 客户端没有直接文件访问能力。

## 加载

- Desktop 启动时加载 client 产物。
- `dsh-client-hmr` 监听 client 入口变化并热替换；修改 `client.js` 后 touch 可触发，无需重启应用。
- 注册/诊断日志写入 `%TEMP%\novel-writer-client.log`。

## 已知限制

- 窄屏下编辑表单密度仍偏高。
- 长章节的滚动锚点还不够细。
- 直接生成 DOCX/PDF 未做；HTML 可打印为 PDF。
