# UI 验收清单（0.1.52）

逐页点检，每项确认后打勾。发现白屏时看页面底部红色错误条（会显示第一条渲染报错）。

## 启动与导航

- [ ] 打开写作台不白屏；顶部显示项目名与路径
- [ ] 左侧步骤栏可切换：项目 / 构思 / 文风 / 设定 / 资料与素材 / 章节
- [ ] 章节页左侧文件树显示卷与章；卷可折叠；当前章高亮
- [ ] 点击章节整行（不只是标题）即可打开该章
- [ ] 章行悬停出现「⇄」，可移动到其他卷；移动后原卷少一章、目标卷多一章、章号不变

## 章节页

- [ ] 中间显示正文；右上可调字号 / 字体 / 行高，稿纸随窗口变宽
- [ ] 吸顶「← 上一章 / 下一章 →」可用，首尾章对应按钮置灰
- [ ] 已打开章节出现标签页，可切换、可关闭
- [ ] 生成正文后自动同步摘要/状态；手动改完可点「更新摘要/状态」
- [ ] 点「修订」后不直接改正文，而是出现「待审阅改动」，展开可看 diff，接受后才写入
- [ ] 提案接受时若正文已被别处改动，提示冲突且不覆盖
- [ ] 右侧章卡：标题、目标字数、章卡要点可编辑，满宽显示；无改动时保存按钮禁用
- [ ] 右侧面板铺满窗口高度，可滚动到「阶段 / 最近运行」

## 项目页

- [ ] 分区标题正确：项目与创作 / 写作要求与素材 / 数据与存储 / 模型与上下文 / 数据与维护 / 流程与工具
- [ ] 模型分配按阶段分组，显示「生效：继承默认/已覆盖」；「全部继承默认」可用
- [ ] 备用模型可选；触发降级后「最近运行」出现「模型降级」，详情显示主/备模型与原因
- [ ] 数据层面板显示文件存储与章节数（不是数据库）

## 构思 / 文风 / 设定

- [ ] 构思页顺序：对话 → 候选 → 已确认构思 → 拆书；候选只有一套渲染，确认后按钮变「已选用」
- [ ] 文风页顶部可直接选模板并套用；「仅保存」与「保存并确认文风」都可用
- [ ] 文风模板管理（保存为模板 / 导入模板）在模板库标题行
- [ ] 设定页分「设定条目」与「结构视图」两行；结构视图只读（关系/能力/伏笔）
- [ ] 设定页新增条目只对条目类生效

## 资料与素材

- [ ] 资料库页可切换「资料库 / 素材库」两个页签
- [ ] 资料可搜索（标题/标签/备注）、按类型筛选，标题显示匹配数
- [ ] 可勾选多条资料并批量删除
- [ ] 新建/编辑资料时切换类型，下方说明随类型变化

## 运行与异常

- [ ] 任务托盘显示进行中/排队任务，可取消
- [ ] 运行详情可查看 model / tokens / 耗时，降级时显示降级信息
- [ ] 任何页面出现异常时，页面底部出现红色错误条（而不是白屏）
