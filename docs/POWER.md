# 能力体系

能力体系是战斗力的唯一基准，不靠正文临时补设定。数据存在 `story/project.db` 的 `power` 表。

## 结构

```json
{
  "system": {
    "name": "武道境界",
    "summary": "一流才可真气外放",
    "tiers": [
      { "id": "second", "name": "二流", "order": 2, "description": "内息贯入兵刃，不能外放" }
    ]
  },
  "characters": [
    {
      "id": "P#01",
      "name": "陆迟",
      "tierId": "second",
      "stage": "巅峰",
      "current": "二流巅峰",
      "abilities": ["《铁骨引气篇》第三层"],
      "notes": "尚不能真气外放"
    }
  ],
  "chapterChanges": {
    "12": ["陆迟：二流巅峰 → 二流巅峰（拳理贯通，无跨级）"]
  }
}
```

## 使用规则

- 先定层级，再定角色当前层级和细分阶段。
- 每写完一章，在「设定 → 能力 → 按章能力变化」登记该章变化；没有变化也要保持为空，不写模糊的“变强了”。
- 变化写法：`角色：旧层级 → 新层级；原因/影响`。
- 正文生成、章纲生成和大纲审校都会读取当前能力与按章变化。
- 不允许无铺垫跨级；跨级必须在章纲/正文中交代功法、机缘、影响或实战积累。

## 上下文

`buildStoryContext` 会注入：

- 层级定义
- 当前出场角色的层级与能力
- 本章登记的能力变化
- 最近三章的能力变化

大纲生成和审校额外读取全部角色能力与按章变化，检查是否跨级。
